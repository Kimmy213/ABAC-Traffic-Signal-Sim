RoiHighlight

Sensing56 linesRuntime

Draws the green tracking box around a car while it is inside a detection zone.

Usesnone
Used byROIZone CameraDirector CarPrefabBuilder
On this page

01Big picture

A display aid with one job: draw a green wireframe box around every car while it is inside a detection zone. That shows an audience, frame by frame, what the camera counts, the same question the computer-vision half of the project answers from drone footage. It changes nothing in the simulation.

  • A global switch, ShowAll, off by default. Press B or the camera bar's button to turn it on.
  • A per-car counter of the zones the car is in, raised and lowered by ROIZone.

02The whole file

The box is a counter, not a flag, so a car on the boundary between two zones stays boxed until it has left both. Update re-checks the global switch every frame: one comparison per car.

The box itself is built by CarPrefabBuilder as twelve thin opaque bars. A translucent solid box was tried first, but in a stopped queue the boxes blended into one green mass and the cars could no longer be counted by eye.
