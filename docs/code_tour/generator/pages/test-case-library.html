01Big picture

The vocabulary for traffic patterns, and the built-in set of them. The file holds no MonoBehaviour: it defines the data types every other part passes around (ArrivalMode, ScheduledBurst, LaneSchedule, LaneArrivalRate, TestCase), plus TestCasePresets, the cases the control panel offers.

  • Scripted cases (T1-T7, T13, Compare-101) release fixed cars at fixed times: identical every run, for demonstrations and logic checks.
  • Poisson cases (T8-T12, ForeverTest) release random cars at given mean intervals, like the batch.
