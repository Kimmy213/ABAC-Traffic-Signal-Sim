01Big picture

The junction written down as data. Both controllers and ScenarioManager look lanes up here and nowhere else, so a lane can be added or removed without touching controller code. The same file also resets every lane at the start of a run and turns a scenario name into reproducible random seeds.

  • Describe: seven ApproachLanes, each with its light, zone and spawner, plus six ConflictPairs.
  • Index: number the five signalised lanes 0-4 and build a 5 × 5 conflict matrix from the pairs.
  • Answer controllers' questions: SignalLight, SignalRoi, AreConflicting, IsCompatibleWithGroup.
  • Reset every lane for a run, with a seed per lane, so Fixed and Adaptive see exactly the same cars.

04Building the matrix

Unity does not guarantee the order of Awake calls between components, so a controller may ask a question before this component has built itself. Every accessor therefore calls EnsureBuilt() first.

Note line 89. isBuilt is set before the conflict loop, because the loop calls SignalIndexOf, which calls EnsureBuilt, which would call Build again and never end.

05The questions controllers ask

Signal indices count only signalised lanes, in list order: A = 0, A2 = 1, B = 2, Bx = 3, CB = 4. Ax and CA have no index; they are found with FindLane.

06Resetting the lanes for a run

A scripted burst at second 0 spawns its first car inside RestartSpawning, and that car registers with its light at once. Clearing the light's registrations later in the same loop would leave that car never hearing that its light turned green. Hence: clear everything first, then restart.

07Seeds that survive a restart

The paired t-test needs Fixed and Adaptive to see exactly the same cars. Each lane's random stream is seeded from the run seed plus a hash of the lane's name. .NET does not promise that string.GetHashCode() gives the same value in every session, so the code uses its own FNV-1a hash:

Try it: the seeds of one batch run

This is StableHash ported to JavaScript and checked against the compiled C#: both give 1879586320 for "MorningPeak". The run seed formula is ScenarioManager.RunSingleExperiment's. Lane seeds overflow and wrap around just as C# int addition does.
