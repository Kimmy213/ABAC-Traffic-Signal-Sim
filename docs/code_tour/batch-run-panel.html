01Big picture

The screen you watch during an 11-hour batch. It appears on the right when a batch starts and shows a full-screen summary when it ends. It only reads ScenarioManager; the one thing it controls is the Stop button.

  • Side panel: progress, elapsed and remaining time, speed, the run in flight, and a Fixed-against-Adaptive table per scenario.
  • Summary: three headline cards and a bar per scenario, with a button that saves a text summary to SimulationResults/.

Before the first run finishes, the remaining time is the theoretical one (1,920 simulated s ÷ 10 per run). After that it uses measured run times, so the number may jump once, and the panel says so:

The saved summary itself says it: these are means for watching, and significance comes from Analysis/analyze_results.py run on the CSV files. The palette (blue for Fixed, orange for Adaptive) is defined at the top of this file and not taken from UITheme.
