01Big picture

The measuring instrument. During a run it collects one record per car that leaves a detection zone and one per adaptive green. At the end it writes the three CSV files that Analysis/analyze_results.py turns into every figure in the report. It is a singleton (DataLogger.Instance), so zones and the controller can report to it without a reference.

  • Vehicles: LogVehicle from ROIZone: lane, driver type, wait.
  • Phases: LogPhase from AdaptiveController: group, G given, G used, why it ended, when each lane emptied.
  • Events: LogStarvationEvent, also from the controller.
  • Export: a detailed CSV per run, a phase CSV per Adaptive run, and one line per run appended to summary_all_runs.csv.

02What is recorded

PhaseRecord exists to measure idle green. Gap-out ends a green only when every lane in the group is empty, so a lane that empties early stays green with nothing to serve. For {B = 10, Bx = 3}, G is 26.05 s but Bx is empty after about 9.9 s, and A is blocked the whole time because it conflicts with Bx. idleLaneSeconds adds up those seconds.

03The numbers a run is judged by

GetAverageWaitTime is the mean over the cars that left a zone in that run. The batch headline (42.03 → 33.62 s) is the mean of those 108 run means per controller, compared pair by pair.

06Known issues

  • NoteThe SODA counters in each summary row (CollectCount, SkippedHeads, QueueStartResets, TieBreaks…) are read from AdaptiveController, which clears them in ForceStop / RestartCycle, before the warm-up. ResetRun after the warm-up does not touch them. They therefore cover 1,920 s, while the phase CSV and the waits cover the measured 1,800 s. In v5 EveningPeak, for example, ties were counted in 2,041 phases while the phase files hold 1,931.From the code: ScenarioManager.RunSingleExperiment lines 436-462 and ResetRun; counts from batch_v5
  • NoteStarvationEvents counts one episode twice: the cut and the override.SODA_BASELINE L13
  • NoteIdle green as a fix was weighed and set aside: measured on batch v2, only 6.1% of it was recoverable by the cheap change, and 49.9% sat in phases where a lane never empties.SODA_BASELINE §8.4
