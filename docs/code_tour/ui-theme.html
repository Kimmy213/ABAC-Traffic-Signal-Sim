Assets/Scripts/UITheme.cs

UITheme

Runtime UI300 linesRuntime

The shared look of every on-screen panel: palette, text styles and small drawing helpers.

Usesnone
Used bynone
On this page

01Big picture

The shared look of every on-screen panel. It is a static class, not a component, and it uses a small trick: Begin() swaps Unity's whole GUI.skin for a themed copy and End() puts the old one back. Every existing GUI.Box, Label and Button between the two is themed without changing a line at the call site. Nine files call it.

All textures are made in memory on first use, so there are no image files to lose, and Ensure() rebuilds them if Unity reclaims them when Play mode switches.

02The palette

Read from the source at build time. The lane colours match the car paint in the scene, and the signal colours are shared by the scene and every panel, so green means the same thing everywhere. This tour uses the same three lane hues, adjusted slightly for contrast on paper.

03Small drawing helpers

Panel, Rule, Pill, Dot, Bar and Row draw the recurring pieces: a titled box, a divider, a status capsule, a signal dot, a meter, and a name-value row. The text styles are Title, H2, Body, Dim, Value, Mono, PillText and Right.
