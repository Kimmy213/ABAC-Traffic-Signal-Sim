TrafficLight

Junction model93 linesRuntime

One signal lamp: holds red, yellow or green, repaints itself and tells every car registered to it.

UsesCarAgent
Used byCarSpawner CarAgent AdaptiveController FixedController IntersectionConfig ABACSceneBuilder
On this page

01Big picture

The smallest runtime component, and the only path from a controller's decision to the cars. A controller calls SetState. The light repaints itself and tells every car registered with it. Cars also read currentState every step, so the two routes back each other up.

  • Hold one of three states: Red, Yellow, Green.
  • Show it by swapping the lamp's material.
  • Tell the registered cars, newest state first to newcomers.

02The whole file

At 93 lines it fits on one screen, so here it is in parts:

NotifyCars walks the list backwards, so cars that were destroyed can be removed while it walks. RegisterCar pushes the current state straight away, so a car spawned during a green does not wait for the next change. The three TEST: context-menu entries (lines 76-93) set a state by hand in Play mode.

One light, two lanes. Lanes A and A2 point at the same TrafficLight object (Light_A). That shared object is what makes SODA's BuildHeads merge them into one head, and what makes Fixed switch them together.
